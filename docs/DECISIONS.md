# 구현 결정 기록

명세(`docs/SPEC_fill.md`)에서 [UNKNOWN]이거나 구현이 어려운 부분을 어떻게 처리했는지 한 줄씩 적는다. 괄호 안은 명세의 관련 절이다.

## 허용 오차와 색 거리

- (5.3) 허용 오차는 [권장]대로 `거리 ≤ 값(%) / 100 × 264`로 판정한다. 임계값은 내림한 정수이고 255를 넘으면 255로 자른다. 83%는 219(흰색 제외), 84%는 221(흰색 포함), 100%는 255다.
- (5.3) 슬라이더 범위는 0~100%, 1% 단위로 움직인다. −/+ 버튼은 1%씩 바꾼다. 값은 실수로 보관한다.
- (5.2) [권장]을 따라, 두 색이 조금이라도 다르면 거리를 최소 1로 둔다. 그래서 허용 오차 0%에서는 완전히 같은 색만 칠한다.
- (5.2) 프리멀티플라이드 방식은 [권장]대로 R, G, B에 각자의 알파를 곱한 뒤 스트레이트 방식과 같이 계산한다. 최소 1 규칙도 곱한 값끼리 비교해 적용한다.

## 채우기 모드와 선택 영역

- (4.1) 연속 모드는 행마다 연속 구간을 단위로 넓혀 가는 방식으로 구현했다. 명세의 스캔라인 절차와 같은 결과(8방향 연결)를 낸다.
- (4.2, 8) 전체 모드도 [권장]대로 선택 영역 밖은 칠하지 않는다. 시작점이 선택 밖이면 아무것도 칠하지 않는다.
- (4.1) 선택 영역이 없으면 캔버스 전체가 대상이다([추측]대로).
- (8) 칠할 곳이 없으면(시작점이 캔버스 밖이나 선택 밖) 놓을 때 편집 대기에 들어가지 않고 작업 기록도 남기지 않는다.

## 경계 처리 (안티앨리어싱)

- (6.2) 세부 공식이 [UNKNOWN]이라 [관찰] 수치를 고정값으로 쓴다. 영역 바로 바깥 1픽셀에서 변 하나가 닿으면 26, 두 변 이상이 닿으면 33, 모서리만 닿으면 8이고, 이 값을 적용 비율(0~255)로 쓴다.
- (6.2) [권장]의 "기준색과 멀수록 낮춘다"는 적용하지 않았다. 관찰 상황(흰 영역 바깥의 검정, 거리 221)에서도 값이 26이었으므로, 거리로 줄이면 [관찰]과 어긋난다.
- (6.2) 부드러운 경계 픽셀도 선택 영역 밖으로는 나가지 않는다.

## 칠하기

- (6.1) 혼합 모드는 "표준"(일반 알파 합성 source-over)과 "곱하기" 두 가지만 두었다. 원본의 공식과 목록은 [UNKNOWN]이다.
- (6.1) 해치 무늬는 가로줄, 세로줄, 빗금, 격자 네 가지다. 6픽셀 간격으로 선은 전경색, 바탕은 배경색이며([추측]대로), 무늬는 이미지 왼쪽 위에 맞춘다.
- (3.2) 샘플링(레이어/이미지)은 UI만 있다. 이 편집기는 레이어가 하나뿐이라 두 항목의 결과가 같다.
- (3.2) 선택 영역 렌더링 품질(부드럽게/보통/빠르게)은 UI만 있고 동작에는 영향이 없다. 항목 이름은 임의로 지었다.
- (8) 투명한 시작 픽셀도 네 채널로 비교하고, 결과는 위와 같은 일반 알파 합성으로 칠한다.
- (8) 레이어 기능이 없으므로 잠금/숨김 레이어 처리는 해당 없다.

## 흐름, 입력, 작업 기록

- (3.2) 확정 버튼은 편집 대기 상태에서만 활성이고, 누르면 결과를 확정한다(Enter와 같음).
- (3.1) Esc는 진행 중인 채우기를 버리고, 편집 대기 상태였다면 "채우기 취소"로 기록한다. Enter는 확정한다.
- (7) 도구를 바꿀 때 편집 대기 중이면 확정하고, 누른 채 그리는 중이면 취소한다.
- (7) 저장할 때 편집 중인 채우기가 있으면 먼저 확정한 뒤 저장한다.
- (6.3, 7) 실행 취소는 기록 단위로 한 단계씩 되돌린다. 기록 이름은 "채우기", "허용 오차 변경" 같은 옵션별 변경, "채우기 시작점 이동", "채우기 색 변경", "채우기 확정"이다.
- (6.3) 허용 오차 슬라이더를 끄는 동안에는 결과만 계속 다시 만들고, 놓을 때 한 번만 기록한다.
- (6.3) 편집 대기가 아닐 때 옵션을 바꾸는 것은 작업 기록에 남기지 않는다.
- (7) 편집 대기 중 기본색/보조색을 바꾸면 처음 누른 버튼의 역할을 유지한 채 결과에 반영하고 "채우기 색 변경"으로 기록한다.
- (7) 핸들은 시작점에 그린 흰 테두리 작은 사각형이다. 화면에서 6픽셀 안을 누르면 핸들을 잡고, 끌면 시작점이 옮겨진다([추측]대로).
- (7) 이동용 핸들은 용도가 [UNKNOWN]이라 만들지 않았다.
- (7) 커서는 페인트통 모양을 직접 만들지 않고 십자 커서를 쓴다. 누를 때 커서도 같다.
- (7, 8) 계산은 동기 방식이라 작업 중 표시와 계산 중단 기능은 없다(1200×900 연속 채우기 기준 수십 ms).
- (3.1) 드래그 중 다른 마우스 버튼을 누르면 진행 중인 그리기를 취소한다([추측]대로).
- (3.1) `F` 키로 채우기 도구를 고른다([추측]대로). B 브러시, S 사각형 선택, M 이동, X 색 교체는 임의로 정했다.
- (3.2) 다른 도구와 허용 오차/모드를 공유하는지는 [UNKNOWN]이고, 이 편집기에는 해당 도구가 없다.

## 다른 기능

- 기본색 기본값은 검정, 보조색 기본값은 흰색이다. 새 이미지는 흰 배경 800×600으로 시작한다.
- 브러시는 가장자리가 또렷한 원형이고, 선택 영역이 있으면 그 안에만 칠한다.
- 선택 영역 이동은 선택 안의 픽셀을 옮기고 원래 자리는 투명하게 만든다. 옮긴 픽셀은 일반 알파 합성으로 붙인다.
- 사각형 선택에서 끌지 않고 클릭하면 선택을 해제한다.
- 열기는 Pillow가 읽는 형식을 RGBA로 바꿔 읽고, 저장은 PNG만 지원한다.
