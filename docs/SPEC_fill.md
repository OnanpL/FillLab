# 채우기(페인트통) 도구 동작 명세

대상 버전: 분석은 5.1.12, 실행 관찰은 5.2에서 했다. 두 버전의 동작이 같은지는 확인하지 않았다.

## 1. 이 문서를 읽는 법

| 표시 | 뜻 |
|---|---|
| **[확인]** | 프로그램 내부 구조나 도움말 문자열로 확인한 사실. 실행해서 관찰한 것은 아니다. |
| **[관찰]** | 설치된 프로그램을 직접 실행해 화면에서 본 사실 |
| **[추측]** | 근거는 있지만 확정하지 못한 내용 |
| **[UNKNOWN]** | 원본의 동작을 알아내지 못한 내용 |
| **[권장]** | 원본의 사실이 아니라, 구현자가 빈칸을 채울 때 참고할 제안 |

[관찰] 표시가 붙은 항목만 실행해서 확인했다. 나머지는 실행으로 검증하지 않았으므로, 화면 표시와 체감 동작은 실제 프로그램과 비교해 확인해야 한다.

## 2. 도구 요약

사용자가 캔버스를 클릭하면, 클릭한 지점의 색을 기준으로 칠할 영역을 정하고 그 영역을 선택한 색이나 무늬로 칠한다. 포인터를 놓아도 결과가 바로 확정되지 않으며, 옵션을 바꾸거나 시작점을 옮겨 결과를 고칠 수 있다.

## 3. 입력

### 3.1 마우스와 키보드

| 입력 | 동작 | 상태 |
|---|---|---|
| 왼쪽 클릭 | 기본색으로 채운다 | [확인] |
| 오른쪽 클릭 | 보조색으로 채운다 | [확인] |
| Shift를 누른 채 클릭 | 이번 채우기만 전체 모드로 처리한다 | [확인] |
| Shift 없이 클릭 | 옵션에서 고른 채우기 모드를 쓴다 | [확인] |
| 누른 채 드래그 | 시작점이 포인터를 따라 움직이고 결과를 다시 계산한다 | [확인] |
| 포인터를 놓음 | 그리기를 끝내고 편집 가능한 상태로 들어간다 | [확인] |
| `F` 키 | 이 도구를 선택한다 | [추측] |
| Esc, Enter 등 | 취소와 완료 기능이 있고 Esc, Enter 키로 실행된다.| [확인] |

- **색과 Shift를 정하는 시점 [확인]:** 포인터를 누르는 순간에 정한다. 드래그 중에는 처음 값을 유지하므로, 드래그 중 Shift를 누르거나 떼어도 영향이 없다.
- **좌표 [확인]:** 시작점은 소수 좌표로 보관하고, 영역을 계산할 때는 x, y를 각각 내림한 픽셀을 쓴다.
- **드래그 중 다시 누름 [추측]:** 진행 중인 그리기를 취소한다.

### 3.2 옵션

아래 옵션이 있다는 것은 확인했다 [확인]. 옵션은 도구 선택 옆의 한 줄짜리 옵션 바에 나열되고, 기본값은 설치 직후 상태가 아니라 이 PC에서 처음 관찰한 상태 기준이다 [관찰]. 별도 표기가 없는 범위와 화면 표시는 [UNKNOWN]이다.

| 옵션 | 설명 | 영향 또는 참고 위치 |
|---|---|---|
| 채우기 모드 | 연속 모드와 전체 모드 중에서 고른다. 아이콘이 붙은 드롭다운이고 기본값은 연속 모드다 [관찰] | 4장 |
| 허용 오차 | 기준색과 얼마나 달라도 포함할지 정한다. 슬라이더 양옆에 줄이고 늘이는 버튼이 있고 값은 %로 표시되며 기본값은 50%다 [관찰] | 5장 |
| 허용 오차의 알파 처리 | 프리멀티플라이드 또는 스트레이트 방식으로 색을 비교한다. 두 항목 중 고르는 드롭다운이고 기본값은 프리멀티플라이드다 [관찰] | 5.2절 |
| 샘플링 | 비교할 색을 어디에서 읽을지 정한다. 켬/끔이 아니라 두 항목(레이어, 이미지)에서 고르는 드롭다운이고 기본값은 레이어다 [관찰] | 이미지는 전체 레이어를 합친 색, 레이어는 활성 레이어의 색 [추측: 실험 전] |
| 안티앨리어싱 | 경계를 부드럽게 처리한다. 사용/해제 두 항목의 드롭다운이고 기본값은 사용이다 [관찰] | 6.2절 |
| 채우기 유형과 해치 무늬 | 단색이나 무늬로 칠한다. 기본값은 단색이다 [관찰] | 6.1절 |
| 혼합 모드 | 칠한 내용을 기존 픽셀과 합치는 방식을 정한다. 기본값은 일반 합성에 해당하는 표준이다 [관찰] | 합성 공식은 [UNKNOWN] |
| 선택 영역 렌더링 품질 | 선택 영역 경계의 처리 품질을 정한다. 기본값은 가장 부드러운 쪽으로 보이는 항목이다 [관찰] | 구체적 효과와 선택 가능한 항목은 [UNKNOWN] |
| 확정 버튼 | 옵션 바 오른쪽 끝에 있다. 채우기 전에는 비활성으로 보인다 [관찰] | 채운 뒤 활성화되는지, 누르면 어떻게 되는지는 [UNKNOWN] |
| 기본색과 보조색 | 앱 전체의 색 설정이다 | 6.1절 |

설정 화면에서 허용 오차와 채우기 모드 항목은 색 범위 선택 도구, 채우기 도구, 색 바꾸기 도구의 공통 그룹으로 묶여 있다 [확인]. 이 도구들이 값을 공유하는지는 [UNKNOWN]이다.

## 4. 채우기 모드

두 모드 모두 시작 픽셀의 색을 기준색으로 삼는다 [확인].

### 4.1 연속 모드

시작 픽셀과 이어진 픽셀 중 기준색과 비슷한 픽셀만 칠한다.

1. 시작 픽셀의 색을 기준색으로 정한다 [확인].
2. 시작 픽셀이 있는 행에서 왼쪽과 오른쪽으로 넓혀 간다. 허용 오차를 넘는 픽셀, 이미 포함된 픽셀, 캔버스 끝에서 멈춘다 [확인].
3. 칠한 구간의 위 행과 아래 행을 검사해, 조건에 맞는 픽셀을 다음에 넓혀 갈 후보로 추가한다 [확인].
4. 후보가 없어질 때까지 반복한다 [확인].

- **비교 기준 [확인]:** 항상 처음 기준색과 비교한다. 바로 옆 픽셀과 비교하지 않으므로, 색이 조금씩 변하는 그라데이션에서는 기준색과의 차이가 허용 오차를 넘는 지점에서 멈춘다.
- **연결 방식 [관찰]:** 대각선 방향까지 8방향으로 연결한다. 두 영역이 대각선 한 점에서만 닿는 그림에서 연속(인접) 모드로 한쪽을 클릭하면 다른 쪽도 칠해졌다. 접점을 이루는 픽셀 한 칸을 막아 두 영역을 갈라놓고 다시 클릭하면 다른 쪽은 칠해지지 않았다.
- **선택 영역 [관찰]:** 선택 영역이 있으면 그 안에서만 칠한다. 선택 안쪽의 영역을 클릭하면 선택 안쪽만 칠해지고 선택 밖의 같은 색 영역은 칠해지지 않았다. 선택 영역 밖을 클릭하면 아무 일도 일어나지 않았다. 선택 영역이 없으면 캔버스 전체가 대상이다 [추측].

### 4.2 전체 모드

연결 여부와 관계없이, 캔버스에서 기준색과 비슷한 모든 픽셀을 칠한다.

- 각 픽셀의 판정은 5장과 같다 [확인].
- **[관찰]** 연속 모드에서 Shift를 누른 채 클릭하면, 검정에 둘러싸인 안쪽 흰 영역과 바깥 흰 영역이 모두 칠해졌다. Shift 없이 안쪽 흰 영역을 클릭하면 안쪽만 칠해졌다.
- 선택 영역 적용 방식은 [UNKNOWN]이다. **[권장]** 연속 모드와 같이 선택 영역 밖은 칠하지 않는다.

## 5. 허용 오차

### 5.1 판정 규칙

픽셀마다 기준색과의 거리를 0~255의 정수로 구한다.

- 거리가 허용 오차 이하이면 포함한다. 거리와 허용 오차가 같은 경우도 포함한다 [확인].
- 기준색과 완전히 같은 픽셀은 항상 포함한다 [전체 모드에서 확인].
- 시작 픽셀은 거리가 0이므로 포함 조건을 만족한다 [추측].

### 5.2 색 거리 계산

**스트레이트 방식**

1. 두 색의 네 채널(R, G, B, A)을 0~1 범위의 실수로 바꾼다. 변환 자체는 [확인], 0~1 범위는 [추측]이다.
2. 네 채널의 차이로 유클리드 거리를 구한다 [확인].
3. 그 거리에 0.5와 255를 곱하고, 0에서 먼 쪽으로 반올림한다 [확인].

네 채널이 모두 최대로 다르면 실수 거리는 2이고 최종 거리는 255다 [추측: 0~1 범위를 가정해 계산].

계산 예시 (0~1 범위 가정):

| 색 A | 색 B | 실수 거리 | 최종 거리 |
|---|---|---|---|
| 불투명 검정 | 불투명 흰색 | 약 1.732 | 221 |
| 불투명 검정 | 투명 검정 | 1 | 128 |
| 투명 검정 | 불투명 흰색 | 2 | 255 |

계산 끝에 최솟값을 보정하는 것으로 보이는 단계가 있지만, 그 역할은 [UNKNOWN]이다. **[권장]** 두 색이 조금이라도 다르면 거리를 최소 1로 둔다. 그러면 허용 오차가 0일 때 완전히 같은 색만 포함된다.

**프리멀티플라이드 방식**

- 알파를 반영해 계산한 뒤 같은 방식으로 거리를 구한다 [확인].
- 이 방식이 기본값이다 [관찰].
- 정확한 공식은 [UNKNOWN]이다. **[권장]** R, G, B에 각자의 알파를 곱한 뒤 스트레이트 방식과 같이 계산한다. 그러면 완전히 투명한 픽셀들 사이의 색 차이는 무시된다.


### 5.3 옵션 값과 거리의 대응

- 허용 오차 옵션 값은 실수로 보관하고, 비교할 때 0~255의 정수로 변환한다 [확인].
- 화면에는 %로 표시되고 기본값은 50%다 [관찰].
- 슬라이더의 양 끝 값과 내부 값으로의 변환 공식은 [UNKNOWN]이다.
- **[관찰]** 불투명 검정과 불투명 흰색을 비교했을 때, 연속 모드에서 허용 오차 83%까지는 흰색이 칠해지지 않았고 84%가 되자 칠해졌다. 5.2절의 계산(거리 221)과 `round(값/100×255)` 변환을 합치면 87%가 되어야 하므로, 이 변환식은 실제와 맞지 않는다.
- **[권장]** 거리(0~255)가 `화면 허용 오차(%) / 100 × 264` 이하이면 포함한다. 264는 위 관찰(83%에서 제외, 84%에서 포함)에서 역산한 근사값이다(221 / 0.84 = 약 263.1, 221 / 0.83 = 약 266.3 사이). 다른 색 쌍에서도 같은 비율인지는 확인하지 않았다.

## 6. 결과

### 6.1 칠하는 색

- 클릭한 버튼에 해당하는 색이 전경색, 나머지 색이 배경색이다 [확인].
- 왼쪽 클릭에서는 전경색이 기본색, 배경색이 보조색이다 [확인].
- 오른쪽 클릭에서는 전경색이 보조색, 배경색이 기본색이다 [확인].
- 해치 무늬에는 전경색과 배경색을 함께 쓴다 [추측].
- 칠하는 대상은 활성 레이어다 [추측].
- 합성 방식과 색의 알파 처리는 [UNKNOWN]이다. **[권장]** 선택한 혼합 모드로 합성하고, 픽셀별 마스크 값(0~255)을 적용 비율로 쓴다.

### 6.2 경계 처리

- **안티앨리어싱 끔 [추측]:** 경계가 또렷하다. 포함된 픽셀의 마스크 값은 255, 나머지는 0이다.
- **안티앨리어싱 켬 [확인, 기본값 [관찰]]:** 먼저 포함 여부 마스크를 만든 뒤, 주변 픽셀과 허용 오차를 함께 고려해 경계용 마스크를 다시 계산한다. 세부 공식은 [UNKNOWN]이다.
- **[관찰]** 안티앨리어싱 사용 상태에서 칠한 영역 바로 바깥의 1픽셀 둘레에 칠한 색이 옅게 섞였다. 검정 위에 빨강으로 칠했을 때 영역과 변으로 맞닿은 픽셀은 R 약 26/255(약 10%), 모서리에서만 닿은 픽셀은 약 8/255(약 3%), 두 변이 영역과 닿은 픽셀은 약 33/255(약 13%)였다. 영역 안쪽은 불투명한 칠한 색이었다.
- **[권장]** 포함된 픽셀에 인접한 비포함 픽셀에 부분 불투명도를 주고, 기준색과의 거리가 멀수록 값을 낮춘다. 원본과 같은 결과를 보장하지는 않는다.

### 6.3 작업 기록

작업 내역에 쓰는 기록은 다음과 같다.

| 기록의 역할 | 상태 |
|---|---|
| 그리기 종료 시 기록 | [확인] |
| 편집 시 기록 | [확인] |
| 채우기 모드 변경 시 기록 | [확인] |
| 확정 시 기록 | [확인] |

허용 오차, 시작점, 색, 혼합 모드 등을 바꿀 때도 각각 별도의 이름으로 기록한다 [확인]. 그 표시 문구는 확인하지 않았다 [UNKNOWN].

## 7. 클릭 후 흐름

```text
대기 ── 누름 ──> 그리기 (드래그하면 시작점 이동, 결과 갱신)
                   │ 놓음
                   ▼
                 편집 대기 (옵션 변경, 핸들 조작 가능)
                   │ 캔버스를 다시 누름
                   ▼
                 기존 결과 확정 ──> 새 채우기의 그리기 시작
```

| 단계 | 동작 | 상태 |
|---|---|---|
| 그리기 시작 | 현재 옵션, 색, 선택 영역을 묶어 작업을 시작한다 | [확인] |
| 드래그 | 같은 색과 모드로 시작점만 바꾼다. 달라진 내용이 없으면 갱신하지 않는다 | [확인] |
| 편집 대기 | 옵션을 바꾸면 결과를 다시 만든다 | [확인] |

아래 기대값은 이 명세에서 유도한 것이며, 실제 프로그램과 대조하지 않았다.

| 번호 | 준비 | 조작 | 기대 결과 |

| 1 | 흰 배경에 검은 닫힌 원, 허용 오차 0, 연속 모드 | 원 안을 왼쪽 클릭 | 원 안쪽만 기본색으로 칠해진다 |
