# FillLab

Windows용 간단한 그림 편집기입니다. 채우기(페인트통) 도구를 중심으로 `docs/SPEC_fill.md` 명세에 따라 구현했습니다.

## 실행

Python 3.10 이상이 필요합니다(tkinter 포함).

```powershell
pip install -r requirements.txt
python src/main.py                     # 빈 이미지로 시작
python src/main.py samples/circle.png  # 이미지를 열고 시작
```

## 시험

```powershell
pip install pytest
python -m pytest -q
```

- `tests/test_acceptance.py`: 명세 9장의 인수 시험 10개
- `tests/test_fill_core.py`: 색 거리, 허용 오차, 8방향 연결, 경계 처리, 합성
- `tests/test_editor.py`: 채우기 흐름(그리기, 편집 대기, 확정), 실행 취소, 브러시, 선택과 이동
- `tests/test_samples.py`: `samples/`의 PNG로 확인하는 [관찰] 항목

## 화면

- **옵션 바(위):** 도구 이름과 그 도구의 옵션이 한 줄로 이어지고, 오른쪽 끝에 확정 버튼이 있습니다.
- **도구 상자(왼쪽):** 채우기, 브러시, 사각형 선택, 선택 이동과 기본색/보조색이 있습니다.
- **상태 표시줄(아래):** 커서 좌표, 이미지 크기, 배율, 마지막 작업이 보입니다.

## 채우기 도구

| 조작 | 동작 |
|---|---|
| 왼쪽 클릭 / 오른쪽 클릭 | 기본색 / 보조색으로 채웁니다 |
| Shift+클릭 | 이번만 전체 이미지 모드로 채웁니다 |
| 누른 채 끌기 | 시작점이 따라 움직이며 결과를 다시 계산합니다 |
| 놓은 뒤 옵션 변경 | 결과를 다시 계산합니다(편집 대기) |
| 시작점 핸들 끌기 | 시작점을 옮깁니다 |
| 다른 곳 클릭 | 이전 결과를 확정하고 새 채우기를 시작합니다 |
| Enter / 확정 버튼 | 확정합니다 |
| Esc | 취소합니다 |

옵션은 다음과 같습니다(괄호 안이 기본값).

| 옵션 | 항목 |
|---|---|
| 방식 | 연속 영역(기본, 8방향 연결), 전체 이미지 |
| 허용 오차 | 0~100% (50%), −/+ 버튼 |
| 알파 | 프리멀티플라이드(기본), 스트레이트 |
| 색 읽기 | 레이어(기본), 이미지 |
| 경계 | 부드럽게(안티앨리어싱 사용, 기본), 또렷하게 |
| 유형 | 단색(기본), 가로줄, 세로줄, 빗금, 격자 |
| 혼합 | 표준(기본), 곱하기 |
| 선택 품질 | 부드럽게(기본), 보통, 빠르게 |

선택 영역이 있으면 채우기와 브러시는 선택 영역 안에서만 동작합니다.

## 단축키

| 키 | 기능 |
|---|---|
| F / B / S / M | 채우기 / 브러시 / 사각형 선택 / 선택 이동 |
| X | 기본색과 보조색 바꾸기 |
| Ctrl+Z, Ctrl+Y (Ctrl+Shift+Z) | 실행 취소, 다시 실행 (한 단계씩) |
| Ctrl+A, Ctrl+D | 전체 선택, 선택 해제 |
| Ctrl++, Ctrl+−, Ctrl+0, Ctrl+B | 확대, 축소, 실제 크기, 창에 맞추기 |
| Ctrl+휠 | 커서 위치 기준 확대/축소 |
| Ctrl+N, Ctrl+O, Ctrl+S, Ctrl+Shift+S | 새 이미지, 열기, 저장, 다른 이름으로 저장 |

## 폴더 구조

```
src/
  main.py       실행 진입점
  app.py        tkinter 화면
  editor.py     편집기 상태: 채우기 흐름, 작업 기록, 브러시, 선택/이동 (UI 없음)
  fill_core.py  채우기 순수 로직: numpy 배열 입력 (UI 없음)
tests/          pytest
samples/        시험용 이미지
docs/
  SPEC_fill.md  명세
  DECISIONS.md  명세의 빈칸을 채운 결정 기록
```

## 명세 표시의 반영

- **[관찰], [확인]:** 명세대로 구현했습니다.
- **[추측]:** 명세대로 구현하고 코드 주석에 "추측"이라고 적었습니다.
- **[UNKNOWN]:** [권장]을 따르거나 가장 단순한 동작을 골랐고, `docs/DECISIONS.md`에 기록했습니다.
